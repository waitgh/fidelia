Questions churches ask

Not answered here? Check the user guide.

Cost

›Is it really free?

Yes, for churches, charities and other noncommercial use. There are no ads and no limits on donors or batches.

Companies that want to sell or resell Fidelia need a separate license from the author.

›What else do we need?

A Dropbox account for each person who records offerings. The free Dropbox plan is plenty: a church file is usually a few megabytes.

A recent web browser: Chrome, Edge, Safari or Firefox. A laptop or desktop is best for counting; an iPhone works for looking things up and light entry.

Privacy and safety

›Who can see our donors and giving?

Only members of your church who have a Fidelia password. Records are encrypted in your browser before they are saved to Dropbox, so the people who run this website, and Dropbox, see only scrambled data.

The website has no ads, no analytics and no tracking scripts.

›Where is our data kept?

In one file in a Dropbox folder that your church owns. The admin shares that folder with the other treasurers. Nothing is kept on our side.

›What if someone forgets their password?

An admin sets a new one for them. When you create your church you also print a recovery key. Keep it with your church’s important papers: it opens the records if every admin is locked out.

Because we can’t read your data, we can’t reset passwords either. Have at least two admins.

›What if we make a mistake, or the file gets damaged?

Every change is written to an activity log, so you can see who changed what. The file is checked before each save, and you can go back to an earlier version from Data & Backup.

›What happens if this website goes away?

Your church file stays in your Dropbox, batches can be exported to CSV and reports saved as PDFs at any time. The source code is public, so anyone can run Fidelia themselves.

Using it

›Can several treasurers use it?

Yes. Each person has their own sign-in name and password, and a role: admin, bookkeeper or view-only. An admin invites people with a one-time code.

One person edits at a time. Anyone else who opens it meanwhile can look but not change anything, and can edit once the first person is done.

›Can we bring in our existing donor list?

Yes. Save your list from Excel or Google Sheets as a CSV file and use Donors → Import CSV. Offering batches can be imported too, from a CSV laid out like Fidelia’s batch export.

›Does it handle Zelle, PayPal and checks?

Yes. Record cash and checks (with check numbers) by hand. Zelle and PayPal gifts can be read from screenshots, and the reading happens on your own computer. You can add your own payment methods and funds in Settings.

›Is it accounting software?

No. Fidelia keeps track of money coming in: offerings, donors, pledges and giving statements. It doesn’t do expenses, payroll or bank reconciliation, so many churches use it alongside their usual accounting tool.

›Who do we ask for help?

Start with the user guide. Fidelia is a volunteer project, so there is no help desk, but you can leave your contact to hear about updates and fixes.
